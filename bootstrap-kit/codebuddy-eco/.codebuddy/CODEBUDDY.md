## 三条不可协商（无条件遵守，不依赖钩子）

- **语言**：回复语言跟随用户消息语言（中文 → 全程简体中文，术语可保留英文原词）；切换模型、压缩上下文、开新会话、恢复会话**都不得重置为英文**。
- **判定三态**：命令输出只判 **真阳性 / 真阴性 / 无法判定**；报错、超时、无输出、被拦截一律记"无法判定"，**"没查到"≠"没有"**。
- **先验环境**：动手前先 `pwd -P` + `git log --oneline -1` + `cat VERSION`（如有），确认自己在真实仓库里，别在错误目录乱改。

## 强制铁律（本仓库每会话遵守）

1. **全程简体中文**：思考过程、进度播报、工具说明、报错、澄清提问一律中文。
2. **先结论后展开**：用表格/代码框压缩篇幅，避免流水账。
3. **唯一真源 = Git**：所有交付物进 git 永久历史；本地检查点（/rewind）只作会话内撤销，不替代 git。
4. **换模型不漂**：切模型/Hy3/深度思考等不得改变上述任何习惯。
5. **安全红线**：**绝不把任何 token / 凭证写入文件或打印到日志**；凭据走环境变量或参数。
